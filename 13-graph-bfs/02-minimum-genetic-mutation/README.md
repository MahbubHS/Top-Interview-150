# Minimum Genetic Mutation

**Difficulty:** Medium | **Category:** Graph BFS
**LeetCode:** https://leetcode.com/problems/minimum-genetic-mutation/

## Problem Understanding
A gene is an 8-character string over `A,C,G,T`. One mutation changes a single character, and every intermediate gene must be in `bank`. Return the fewest mutations from `startGene` to `endGene`, or -1.

## Approach
Genes are nodes; two genes are connected if they differ in exactly one character and the target is in the bank. Fewest steps in an unweighted graph → **BFS**. Neighbors are generated by trying all 3 other letters at each of the 8 positions.

## Algorithm
1. Return 0 if start equals end; return -1 if `endGene` is not in the bank.
2. BFS from `startGene`, tracking steps.
3. For each position try the other three letters; enqueue unseen candidates that are in the bank.

## Dry Run
start `AACCGGTT`, end `AACCGGTA`, bank `[AACCGGTA]` → one mutation → `1`.

## Complexity
- Time: O(B × 8 × 3) where B is the bank size
- Space: O(B)

## Edge Cases
- End gene not in bank → `-1`.
- Start gene need not be in the bank.
